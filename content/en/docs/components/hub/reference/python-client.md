This page describes the standalone `model_registry` Python client. Please see its
[reference documentation](https://model-registry.readthedocs.io/en/latest/) for more information.

The Kubeflow SDK also includes `kubeflow.hub.ModelRegistryClient`. See the
[Kubeflow SDK Hub documentation](https://sdk.kubeflow.org/en/latest/hub/) for its API
and setup instructions. The two clients have different packages and APIs; choose the one that
matches the interface used by your application.
