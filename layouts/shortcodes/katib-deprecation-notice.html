Deprecated

The Katib project is deprecated. Users should migrate to the OptimizationJob APIs, which are released as part of the Kubeflow Trainer project under alpha feature gate.

OptimizationJob is the next step for hyperparameter optimization in Kubeflow. It is natively integrated with the TrainJob API, so every trial can use Trainer runtimes and distributed training features out of the box. Metrics are pushed through the Kubeflow SDK and Trainer status server, so you no longer need a separate database or a metrics collector sidecar.

Work on the remaining features is tracked in kubeflow/trainer#3562.
